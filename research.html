Methods & Results

A compact technical view of the current CitySafe pipeline, the evaluation setting, and the main findings from the audited run.

Technical Overview

CitySafe is built around a practical comparison ladder. We start from text baselines, add structured context, and then study linked media on the smaller linked subset. The current package supports text records, context features, linked short-video features, and optional subtitle or ASR text when it is available.

At this stage, the clearest gain comes from context-aware modelling on the full suite. Linked media is part of the study, but the smaller linked subset means those findings are still earlier and more tentative than the larger full-suite results.

At a glance

  • Current prototype stage: TRL 4
  • Best current full-suite setting: linear text + context
  • Active video branch: sparse keyframes + ResNet-50 + Bi-GRU
  • Reserved text pathway: 768-dim interface awaiting semantic encoder integration

System Overview

The system is structured as a modular pipeline, so data preparation, training, and prediction can be rerun under one reproducible setup.

Inputs

The package works with text, label, platform, timestamp, group or session identifiers, video paths, and optional subtitle or ASR text where available.

Context branch

Structured features such as reply activity, mention count, platform information, and coarse time bins are used to give the model more than local text alone.

Linked media branch

On the linked subset, text, context, and short-video features can be fused through a gated multimodal head, with missing-modality handling kept in mind.

Outputs

The system produces risk scores, selected thresholds, confidence-oriented summaries, CSV exports, and visual analysis charts that are easier to connect to later review.

Training and Evaluation Pipeline

Our pipeline enforces strict data splits, saved artifacts, and shared evaluation logic across model families.

1

Prepare

Data is written into a manifest-style format. Cleaning, label mapping, media linking, and group-aware train/validation/test splitting are handled before model training.

2

Train

The current comparison includes linear and neural text baselines, context-aware variants, and linked-media runs on the smaller linked subset.

3

Select operating points

Threshold selection and optional temperature calibration are included because probability quality matters, not only the raw label after a fixed 0.5 cutoff.

4

Predict and review

The same package supports batch prediction, saved reports, and visual analytics, linking model output to the review flow shown elsewhere on the site.

Implementation Status

The current invention disclosure records CitySafe at TRL 4. The active video branch already uses sparse keyframe sampling, a pretrained ResNet-50 backbone, and Bi-GRU temporal modelling. Batch inference, visual analytics, and the broader system architecture have also been completed for the present prototype stage.

One important open item is the text branch. The reserved 768-dim text pathway is already in place, but it is still waiting for genuine semantic encoder integration. This is one of the main upgrades planned for the next round.

Next steps

  • Connect the reserved text pathway to a semantic encoder
  • Improve minority-class recall through focal loss or oversampling
  • Clean metadata to strengthen video-text linkage
  • Implement the Evidence Kit, audit log, and RBAC modules
  • Continue privacy and latency work for later deployment discussion
