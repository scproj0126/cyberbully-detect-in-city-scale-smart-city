Toward Multi-Modal and City-Scale Approaches

Cyberbullying identification and detection in social networks under smart-city settings

In smart-city contexts, aggressive language and cyberbullying on social platforms can spread rapidly and amplify negative impacts. Although text-only models have become relatively mature, real-world city-scale deployment still faces challenges such as cross-platform domain shift, class imbalance, and weak performance on minority bullying types. This project proposes a reproducible multi-modal detection pipeline centered on text semantic representations, while integrating structured context signals (e.g., temporal and interaction statistics) and cross-platform link context (e.g., Tweet–Vine mapping identifiers from the Vine Tweet archives) to capture propagation and association patterns in a lightweight manner. We will systematically compare classic machine learning and pretrained transformer baselines, and quantify the gains brought by the “link-context modality” via ablation studies, with a focus on macro-level metrics and minority-class recall to produce conclusions and practical insights aligned with smart-city governance needs.

About the Project

This project compares classic machine learning methods and transformer baselines under a reproducible evaluation framework, and builds a multi-modal detection workflow by fusing structured context signals with cross-platform link context signals. The study focuses on domain shift and class imbalance, and uses ablation experiments to quantify how the link-context modality improves minority-class detection and overall robustness.

Datasets

We build on public cyberbullying / abusive language datasets and prioritize sources that contain structured context or cross-platform link cues to support multi-modal modeling and city-scale analysis. During data preparation, we perform de-duplication and normalization, define explicit label-mapping rules, and use stratified splits with fixed random seeds to reduce leakage and ensure reproducibility. When Tweet–Vine mappings are available, we extract linkage identifiers to construct the “link-context modality.”

Models & Methods

Under a unified evaluation protocol, we establish a baseline suite including classic ML models (e.g., TF-IDF + Logistic Regression / Linear SVM) and transformer text baselines (e.g., fine-tuned BERT / RoBERTa). Building on these, we introduce a multi-modal fusion framework that jointly encodes text representations and structured context signals (temporal features, interaction statistics, etc.), and, when available, incorporates cross-platform link context (e.g., frequency and temporal spread features of URL/video identifiers). A lightweight context encoder and fusion module are used to improve robustness to domain shift and noise.

Future Work

Next steps will focus on “modality lift” and deployment usability. We will conduct ablation studies comparing a text-only model with a fusion model (text + link context), emphasizing improvements in macro-level metrics and minority-class recall. We will also include robustness tests (e.g., noise perturbations and cross-domain evaluation) and statistical reliability analysis to assess stability and produce interpretable conclusions under city-scale settings. If feasible, we will further extend richer conversation-graph features and cross-platform propagation pattern modeling.

Key Contributions

  • Unified baselines and reproducible evaluation protocol: Fair comparisons of classic ML and transformer baselines under the same data splits, fixed seeds, and consistent evaluation pipeline.
  • Link-context modality (Link-context Modality): Lightweight structured context features built from cross-platform linkage identifiers (e.g., Tweet–Vine link IDs) when available.
  • Robustness design for city-scale deployment: Robustness checks targeting domain shift and noise perturbations to reflect practical deployment constraints.
  • Imbalance-aware evaluation and error analysis: Reporting macro-level metrics and minority-class recall, complemented by targeted qualitative error analysis.
  • Modality-lift ablation (Modality Lift Ablation): Systematic comparison between text-only and “text + link context” fusion models to quantify the value of structural social signals.
