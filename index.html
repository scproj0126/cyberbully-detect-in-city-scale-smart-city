CitySafe · CDS553 course project

Toward Multi-Modal and City-Scale Approaches

Cyberbullying identification and detection in social networks under smart-city settings

CitySafe is our course project on cyberbullying detection in social networks. We are exploring how text signals, contextual clues, and linked media can be brought into one clearer workflow for screening and follow-up.

Alongside the model work, we built a small interface concept to show how a user might submit a case, read a result, save evidence, and move flagged items into moderator review.

Project Overview

CitySafe connects cyberbullying detection with a clearer smart-city-oriented review and evidence workflow.

The workflow begins with a message or screenshot check, moves to a readable result and evidence summary, and ends with moderator-side review for higher-risk cases.

POSITIONING & DIFFERENTIATION

How CitySafe Differs

CitySafe is built as a smart-city-oriented pilot for cyberbullying risk screening and evidence packaging — not a fully automated enforcement tool, but a system designed to support structured human review and follow-up.

01 / Positioning

CitySafe is a smart-city-oriented pilot for cyberbullying risk screening and evidence packaging, designed to support human review rather than automatic punishment.

02 / Workflow Focus

Unlike systems that only score isolated text, CitySafe is built around a practical workflow: screening, evidence organization, and structured follow-up support.

03 / Multimodal Input

The current design combines text, image, OCR, and selected video context to support more robust case assessment in real-world reporting scenarios.

04 / Privacy-Aware Design

Sensitive materials are handled with a privacy-aware, local-first approach, with assistive outputs and explicit user control over evidence sharing.

05 / Human-in-the-Loop

The system is intended to assist users and reviewers with risk signals and organized case materials, not to replace human judgment.

06 / Prototype Scope

This is a pilot-stage system focused on practical integration and feasibility, rather than a claim of full commercial-scale moderation coverage.

System Inputs

The current study combines text records, structured context, linked short-video features, and optional subtitle or ASR text when available.

Training Pipeline

The package now follows a clearer prepare-train-predict structure with split control, saved artifacts, threshold selection, and optional calibration.

Current Best Result

On the full suite, the strongest overall setting in the current audit is the linear text + context model, with 0.776 macro-F1, 0.792 harmful recall, and 0.532 AUPRC.
